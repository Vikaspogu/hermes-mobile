Three dark theme candidates for Hermes PWA

Same home screen, same content, three palettes. Each is grounded in a battle-tested dark system (Linear, Catppuccin Mocha, iOS dark). Contrast ratios below each frame are computed live (WCAG). Semantic colors stay distinct from the accent in every scheme: success green, warning amber/yellow, danger red never double as the brand accent.

Recommendation

  • T1 Midnight Indigo — the professional default. Linear-grade near-black with a single indigo accent; closest to the current theme so it reads as an upgrade, not a change. Best contrast discipline.
  • T2 Mocha Mauve — the rich one. Catppuccin Mocha's warm purple-black with pastel accents; buttons use light mauve with dark text, which pops hardest on a phone. Dev-tool personality.
  • T3 Graphite Cyan — the mobile-native one. True-neutral graphite (no color cast) with iOS-style cyan; feels the most like a first-party iOS app.
  • Implementation: each scheme is one [data-theme="…"] token block in packages/web/src/styles/tokens.css (semantic tokens already in place — the accents/ink/bg swap per theme) plus a picker under More → Settings → Appearance → Theme: System / Light / Dark · Indigo / Dark · Mocha / Dark · Graphite. Light theme and M8 voice screen stay untouched.
